## 2. 源代码模块索引

路径均相对于 `src/continuity_engine/`：

- `domain/`：SubjectState、P03 Event/Evolution/Timeline、P04 Memory/DerivedSummary、P05 context routing/manifest/trace、P06 context composition/authority/snapshot/trace、Wake、Perception、Thinking、Action、Permission、Learning、Resource、SubjectBinding、Integration/Capability 契约，以及 P02 宿主中立模型执行事实与不变量。
- `services/`：主体状态、P03 只读 Timeline、P04 Memory Consolidation/summary/retrieval、P05 Context Router/只读 source/permission、P06 Context Composer/exact resolvers、Wake/Perception/Thinking/Action、Learning/Resource、机器契约、Capability、P02 Provider Port/Profile/协调与唯一 `ContinuityInteractionService` 编排。
- `storage/`：本地 JSON 与内存仓储实现；SubjectState、P04 单一 Memory/Summary/lineage 文档、Wake、Thinking、Permission、Learning、Resource、Binding、operation/result/capability ledger，以及 P02 execution/usage/test-credit 测试账本。
- `interfaces/`：进程内 API、调试 HTTP、正式 IntegrationAdapter/回环 HTTP、Schema registry、P02 本地模型能力装配、MCP/Skill 设计边界。
- `frontend/`：Engine 本地调试前端静态资源，不是 Vio 或生产前端。
- `integration_server.py`：正式本地回环 Integration 服务的显式 init/serve CLI。
- `cli.py`、`__main__.py`：Engine 本地状态管理 CLI。
