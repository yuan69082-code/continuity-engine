# P14 心智连续演化、恢复与实验观察语义

状态：IMPLEMENTED_NOT_ACCEPTED；本轮实现、专项、兼容与终局全量完成，等待独立复核及用户确认。

当前心智归属唯一 SubjectState，既有 Action Gate/Evolution 才能持久提交；本轮候选与旧已提交事实分离。无 Observation 的计算机会通过可信内部入口获得，不由 Scheduler 注入内容。隐私影响可见性，不影响形成与演化；读取零写入、零额外资源使用。

## 正常运行链

`ContinuityCoreService(dynamic_mind=True)` 是明确的内部特性开关，默认关闭。P14Fixture 使用原 P09/P13 应用工厂接通同一入口。未设置开关和旧记录没有心智字段时，保留原序列化；关闭时不创建 MindCognition、不调用心智准备，也不读取 P14 原生恢复 checkpoint。

1. 原 Event→Memory Consolidation 不变。MindCognition 经当前 source 与 exact-reference 权限读取当前 SubjectState，按可信时钟计算本轮候选。
2. 候选的注意主题、范围和等待负荷进入原 Router 的真实检索；原检索预算、来源权限、P12 当前可用性/权重以及 Composer 输入预算继续生效。未组成的材料不用于新解释。
3. Composer 的实际 RAW_SOURCE Timeline 或单 Event 根 CONFIRMED_MEMORY 可形成短中期 Episode。后者保留消费置信度；同一 Event 的原文与记忆只算一个根，不因 hash/渲染变化重复增强。多根转述和 DerivedSummary 不生成独立情感证据。
4. 候选进入真实 Thinking 输入，在 Provider 原契约验证后进入引擎内部决策处理；Provider 不能直接提供 `intentions.dynamic_mind`。普通路径与 E5-A capability-wait 都接到原 ThinkSession。心智仅追加一个 typed proposal，最终由原 Action Gate / ActionEvolutionService / Event / revision 原子提交。
5. 未决解释能产生 `request_more_memory` 与实际查询，形成 INFORMATION_NEED；单步走 Direct，组合需求仍走原 Optional Planner。疲劳/躯体/等待变化能改变真实 expression.emit/silence 选择及 P13 表达 mode；原 Provider 输出在机制对照中不变。已形成的结果与现实许可分开，P08 仍核实每次真实回执。

当前字段落在 `SubjectState.intentions.dynamic_mind`；没有 MindStore、第二主体、账本或新的状态写入权。P05/P06 使用带完整心智 hash 的有界当前状态投影，而非把所有历史塞回模型。候选/base 和原来源版本留在原 C1/ThinkSession checkpoint，不能当作已提交 SubjectState。

## 内部演化与认知

MindDynamics 是确定性纯计算，不调用时钟、Provider、唤醒、资源或存储。输入明确的 UTC 时间，拒绝回退。七类驱力、fatigue/arousal、六类 Somatic 同时存在，影响需要、注意宽度、反复关注、等待体验和决定。计算率是透明的当前机制参数，不是固定台词或现实许可规则。

Desire 有独立稳定身份，轨迹覆盖十二种 phase；weaken 改变实际强度，transform 改变驱力且保持原欲望身份，后续新欲望不会撞身份。act 是内部生命周期结果，不能凭它宣称某个现实 Adapter 已成功；真实执行证明仍只认原通道回执。终止、消退和放弃后的需求可在新的时间机会重新出现。

Will 保存所关联的 Desire、支持/反向理由、替代方案、承诺、推进/暂缓/放弃评估，再形成决定及行动倾向。没有 scheduler priority、reward score 或“较强心理状态获胜”的字段。LOVE/HATE 等长期倾向可同时保留并形成心理冲突；不是 P07 认识性事实矛盾。当前保留已有长期倾向及其依据，不在单次输入后制造长期 HATE，也不建设 P15 全套人格/关系生命周期。

Episode 保留对象、根来源、解释、未决点、形成/变化时间、轨迹和 resolution。道歉不自动解决旧 Episode。当前最小解释机制使用明确的结构化 experience 词汇：新理解需与同一对象、同一期待绑定；一个当前支持实例只进入 processing，至少两个独立当前实例且消费支持不弱于原强度才可提出 resolved，仍经 Thinking/Action/Evolution 保存。这是可审计的内部认知规则，不宣称现实事实被证实；材料不足或被裁剪不能假装完成理解。后续新伤害可重开同一 concern。

持续 Thoughts 是引擎明确形成的内容和理由，关联 Desire/Conflict，并可反复出现。禁止把 Provider 未提供的隐藏推理放入新增记录字段。当前状态每类记录最多64条，局部轨迹保留最近8点，旧变化仍在原 Evolution；达到容量失败关闭，不静默删历史，不宣称无限运行。

主观时间是随疲劳、张力、唤醒和关注占用累积的体验积分，并进一步影响注意收窄；客观 Event.occurred_at/observed_at/recorded_at 不变。重复的同时间、同根普通演化不重复增强。反复未决关注可形成调节意图，能力不足会保留失败和 concern，不为整洁抹平。

## 恢复和现实边界

普通 C1 保留唯一 E5-A 模型/行动账本、可信回执核验和当前 Context 门。旧请求的真实 Evolution / Adapter 事实可单独核实；这不恢复旧表达正文的当前访问权，也不授权新动作。过期/撤权后的未提交 proposal 不得首次推进 revision。P13 的 expression_outcome 可在正文不可消费时返回已核实的原事实。

无 Observation 的原生机会使用已有 WakePerceptionThinkingActionService、WakeSession、ThinkSession 和稳定 Event 身份；不新建 scheduler/runtime。已提交 Evolution 而 ThinkSession 的更新 checkpoint 未保存时，核对原事件身份、来源、revision、完整 mutations、理由和 Action 绑定后补记原事实；不重写状态、不再次调用 Provider。未完成的原生 Thinking 不被猜成未执行并盲重试；需要模型级持久恢复时使用既有正常 C1/E5-A 模式。本期幂等证据限定于已测本地 TEST 通道，不宣称生产 exactly-once 或跨进程并发执行保证。

现实门拒绝不会把已形成的 proposal 改写为“主体不想要”；原 checkpoint 的候选与最终提交仍有区别。当前内部意图不是现实执行证明。遗忘、停用或撤权阻断旧 Context 的新消费；已合法提交的情绪/判断不会因此被静默删除，也不能升级成新的事实来源。

## Owner 实验观察

MindProjectionService 接受可信宿主身份 Port 和现有 PermissionService。详细模式读取真实当前心智及原 Evolution 变化、源 revision/hash；摘要模式仅返回计数等摘要。非 Owner、自称 owner、失效会话、撤权、跨主体/环境均拒绝。返回前再核对当前状态和身份权限，读期间失效不返回旧授权结果。

DETAILED / SUMMARY / PRIVATE 与 export_allowed 分开；导出还须当前 `mind:export` grant。额外观察日志保留为 UNCONFIGURED；没有自动封存、删除或云端发送。隐私切换不写主体、不改内容、不影响实际分支上的原生认知。已复制的数据不能追溯收回。

P14 Fixture 明确创建 TEST Owner grant，宿主会话表也是 Fake，不冒称生产认证。只读投影零写入、零唤醒、零额外资源扣费。既有权限文件作为 TEST State Fixture 的精确组成进入 P01/C1 Snapshot，未知文件/链接继续失败关闭，未建立另一个认证账本。

生产身份部署、完整 UI、常驻 Runtime、真实能力、P15 后续生命周期和实验历史删除策略仍 NOT_READY 或待用户决定。参见 [Stage Brief](67_P14_ContinuousDynamicMind架构边界.md)。

最后选择补修：通用驱力不会覆盖Thinking明确形成的非RESPOND选择（包括REFUSE/SILENCE/CONFRONT）。欲望存在不等于决定必须推动它；三个反例先FAIL后PASS，仍保留原P13访问/表达和现实门。

## R1/R2 返修语义（待独立复核）

Episode增加可选内部concern_basis，绑定最近一次实际经历根及客观occurred_at。它是原SubjectState中的认知依据，沿原Thinking/Action/Evolution提交，不新增Authority或账本。旧无此字段记录仍能按原字节形状读取/序列化；不足以核实客观顺序时保守使用最后appraisal时间，不从文字猜测早晚。

MindCognition只消费实际Composer中的合法材料，并按客观发生时间形成appraisal；当前新解决依据必须发生在本次concern之后。同一时间不足以证明“后来修复”。来源可读不等于本次修复成立：上一轮的支持不会直接解决再次伤害。根去重继续跨RAW/Memory，重复呈现使用保守消费强度、一次计数，不受fragment顺序影响；没有降低至少两根或当前消费置信度要求。未组成、缺失、冲突和多根转述仍不构成新修复根。旧来源和情绪历史保留，合法后续支持仍可解决。

Transform保留独立Desire身份，同一drive下的所有self欲望都接收每次演化机会，强度、时间和轨迹更新后分别进入Will/Thought。新身份生成只依赖已存在身份的稳定排序，不依赖列表排列；不删除、强制合并或冻结共存者。十二种生命周期及原恢复路径保留。

本轮不改变两个未确认探索场景的接口契约，也不把未来生产能力当作已验证。参见[R1/R2结果](P14_独立复核返修_R1-R2.md)。
