# W02 回答前回忆超时：预定验证协议

本轮只处理已验收 W02 的回忆耗时，不改 1000 毫秒政策。历史 `integration-draft-01` 和 `w02-paired-diagnostic-01` 原样保留；旧版单次测量不作为当前版的重复结果。

1. 先在当前源码上原样运行第三轮/16 项的正式集成用例一次，保留完整输出。另以正常原始消息入口构造四份资料负载，保存修前结果。
2. 定点测量各执行站：Router、来源/权限复核、Composer、候选解释，以及 operation journal 的字节读取、完整解析/校验与副本构造。测量运行与未装仪器的业务耗时分开记录；仪器自身增加的耗时不计入产品时限证明。
3. 最终代码固定后，对上述两个负载各做预先固定的三次独立运行；保存三次全部结果，不按通过情况增加次数。定点安全/恢复对照、W02 与 W03 兼容各运行一次，最后全量一次。若出现新的失败，保留首次现场并先查原因。
4. 每次运行记录命令、退出码、起止时间、耗时、标准输出/错误、运行前后源码指纹。SKIP、FAIL、ERROR、中断和旧历史结果分别统计。

不以仪器测量的较慢运行直接推断生产性能，也不以单次通过宣称不会再超时。
