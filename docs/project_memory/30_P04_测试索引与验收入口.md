## 4. 关键验收断言

- Memory kind 与 evidence type 使用唯一正式术语；`episodic` 不能成为 evidence type。
- 四时间与 time range timezone-aware 且规范化 UTC；来源链、根证据、subject/environment、revision/version 全部失败关闭。
- JSON document hash、逐对象语义、连续历史和 lineage 在每次加载时重新验真。
- 相同根证据经多个 identity、检索、重放、Summary 或重启只贡献一次。
- 冲突证据不静默合并；P07 未提前施工。
- 温度迁移只由显式入口触发，没有过期、物理删除或 Scheduler。
- DerivedSummary 与 Memory/lineage 共用一个仓储，固定生成器下可重建，来源变化后旧版本失效。
- correction/revocation/deletion 追加墓碑并使依赖摘要失效，不删除 Event 或原 Memory 版本。
- Consolidation/Summary/检索不产生 Event、StateMutation 或 SubjectState revision。
- Learning 按 root evidence 去重；Summary 不是独立学习事实。
- P03 Golden Scenario 中 intention 与 fact 分离，争执/和解顺序稳定，当前关系仍由 SubjectState 表达为 reconciled。
- 正式 `.continuity-data`、六份 Schema、`pyproject.toml`、版本、Vio、网络和凭据均保持不变。
