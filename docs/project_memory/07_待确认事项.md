# 待确认事项

> 本文件记录已在路线或接口中出现、但尚未获准作为当前实现范围的能力。它们不是“已经完成”，也不是“永久拒绝”；开发前必须取得明确批准并补充架构决定。

## 1. Execution Engine

**已提出内容：** 执行 ActionPlan，调用工具、联系用户或处理外部副作用。

**当前状态：** 未批准进入当前版本；Action 阶段明确禁止真实执行。

**待确认：** 执行权限模型、确认流程、幂等、失败/补偿、审计、沙箱和回滚边界。

## 2. 真实 AI API

**已提出内容：** 让 GPT、Claude 或本地模型实现 ThinkingProvider，未来也可能辅助 Perception 或 Learning。

**当前状态：** 仅有可插拔接口，没有真实调用。

**待确认：** 首选 Provider、数据出境、隐私、超时/重试、输出校验、模型降级和成本策略。

## 3. 真实 MCP 连接

**已提出内容：** 通过 MCP 读取状态、查询记忆、感知、思考和行动计划。

**当前状态：** 只有 `ContinuityMCPAdapter` 接口设计。

**待确认：** MCP server/client 角色、工具暴露范围、鉴权、权限映射、资源计费和错误协议。

## 4. 外部长期记忆库

**已提出内容：** 通过 MCP、向量库或其他存储提供长期记忆检索。

**当前状态：** Memory 管理层只有检索和影响接口，不保存长期记忆。

**待确认：** 数据所有权、删除/更正、召回策略、相关性阈值、敏感信息、去重和迁移。

## 5. 主动联系用户

**已提出内容：** CONTACT_USER 计划最终转为真实消息。

**当前状态：** 只能生成计划；不能发送。

**待确认：** 渠道、频率、安静时段、用户确认、撤销、内容审核和失败处理。

## 6. 真实外部工具调用

**已提出内容：** USE_TOOL 计划最终调用浏览器、邮箱、日历、设备或其他工具。

**当前状态：** 只能生成计划；不能调用。

**待确认：** 工具白名单、参数校验、最小权限、沙箱、确认、结果可信度和副作用恢复。

## 7. 常驻自主运行与自主唤醒

**已提出内容：** 定时或持续后台唤醒，甚至根据事件自动运行。

**当前状态：** 有 WakeCycle/资源感知调度框架，没有常驻守护进程。

**待确认：** 生命周期、频率上限、关停开关、资源配额、异常熔断、时区和用户可见性。

## 8. 情绪模拟

**已提出内容：** 让主体拥有模拟情绪或情绪驱动行为。

**当前状态：** 当前阶段多次明确禁止；`emotion_state` 字段不等于情绪模拟系统。

**待确认：** 是否符合项目目标、与 Perception/Personality 的边界、用户误解风险和安全约束。

## 9. 自动永久人格改变

**已提出内容：** 系统自行学习并永久改变 PersonalityTrait。

**当前状态：** 未批准。当前学习必须多证据、验证、明确确认，并可回滚。

**待确认：** 人工确认责任、可解释性、错误恢复、冻结特征和策略版本。

## 10. 模型训练或参数更新

**已提出内容：** 通过经历训练模型或修改权重。

**当前状态：** 不属于 continuity-engine 当前定义，明确未实现。

**待确认：** 若未来提出，应作为独立项目评估，而不是 LearningService 的自然延伸。

## 11. 真实平台权限

**已提出内容：** 手机、浏览器、邮箱、日历、MCP 和工具权限接入。

**当前状态：** PermissionState 与 PermissionProvider 只处理内部状态/测试判断。

**待确认：** 平台授权协议、过期/撤销同步、scope 映射、凭据存储和重新确认机制。

## 12. 用户认证、多租户与支付

**已提出内容：** 登录用户 ID、多主体、资源购买或外部支付。

**当前状态：** 仅预留 subject_id；没有认证、租户或支付系统。

**待确认：** 身份模型、主体与用户映射、数据隔离、账单归属和合规要求。

## 13. SSE / WebSocket

**已提出内容：** 前端实时事件和状态推送。

**当前状态：** 仅作为未来扩展预留，未实现。

**待确认：** 事件类型、重连、顺序、鉴权、资源限制和是否确有产品需求。
