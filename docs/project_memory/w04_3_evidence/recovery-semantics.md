# 接入、使用与恢复语义

N14 的候选来自已授权 P16 发现查询的原始回执。ToolOffer 只是带版本、用途、依赖与 Attachment 的外部候选；不会授予权限。ToolLease 是原结构化 Action 的参数，记录单次/限时/持续、范围、到期时间、受控凭据引用和 TEST 预算。新的工具没有预先登记为当前可用。

发现 → 当前来源/身份/范围核查 → tool.connect → tool.verify → 原 Attachment 登记 → device.* 使用 → tool.close。每一步都经原 P08 ActionPlanning、P17 current 检查与 E5-A 请求/结果；阶段、等待点、成本和清理情况从这些原事实重建。服务不维护第二请求表或结果账本。TEST 外界的连接文件是 Fake 的模拟世界，不是 Engine 事实权威。

已有有效条件时 `advance` 一次有界续接能完成原工具任务，无逐步模型调用或人工审批。缺 LOGIN/NEW_SCOPE/BUDGET/依赖时保留原请求；协助完成后按当前条件重查。`TemporaryToolRuntimeWork` 是原 P18 work 的可选适配，复用 Scheduler 与 guard；不是第二运行时、常驻服务或自动重启。PAUSE/STOP 保持，原未知效果仍先查询。

连接成功不等于验证成功；Attachment 注册也不能替代验证回执。行动和纯观察都检查当前临时资格。新观察返回前再次检查，失权不交出内容。界面路径不是权限替代；仅已证明未执行的技术不可用可以经 P17 选合法替代路线，权限拒绝与 UNKNOWN 不适用。

单次成功后不能再执行第二个业务动作，自动续接会提出结束；限时及持续连接在任务结束后保留到其约定期限或明确取消/撤销。持续不是永久授权，租约仍有期限。续期必须用新有效 grant 和新连接身份；旧到期资格不复活。

尚未接入时的取消也绑定原连接请求。已登记close会阻止原connect新增连接；只有明确NOT_EXECUTED或已有可靠终态，清理才可继续检查并结束，UNKNOWN不会当作未发生。若当前P17执行锁仍忙，取消已保留为待清理；锁释放后以同一清理请求续做，不要求嵌套锁内假报完成。

清理具有独立授权且仍绑定当前 host/generation、原主体、连接和 Action。使用被撤回后可以获准清理，但旧宿主失权不会因此恢复执行资格。失败/PARTIAL 为 PENDING_CLEANUP；UNKNOWN 为 CLEANUP_UNKNOWN，不宣称断净。原请求的返回丢失可恢复原回执，不重建连接、不重复业务或扣费。连续失败的自动清理最多三份有明确关联的清理动作，之后保留待清理与限制标识；没有无限重试或删除正式 Event。

模型生成仍由原 ThinkSession 管理；本批普通工具输出仍是 Result Observation，不直接修改 SubjectState。使用经历与失败在原请求、事实和回执中保留，可只读查看。完整长期内化仍经既有 Learning/Evolution，不由接入器直接写人格。

原 W02 1000ms、指定历史查询 2048 Context、P18 0.25s 等待及旧授权/生命周期不变。查询示例复用 W04-2 `device.query`、指定回执 Router/Composer、当前来源核验；自然记忆及人格联动归 W05。

公共接线是按设备服务实例显式选择的 `connection_guard`：装配临时工具路线时接入本服务，原普通设备/身体调用的默认值仍为None。接入了该门禁的实例只放行已有对应临时连接事实的请求；不能把该实例无区别替换成所有普通设备的全局入口。完整跨入口装配及联验归W04-4，本批不宣称完成该项。

P18 宿主保留每次最多两个 need 的原上限。本批可选 work 适配在存在待接入工作时提供首个 native need 与首个工具 need；专项实测是单个接入事务的等待、暂停、恢复、停止。多个同时待接入事务的公平推进尚未取证，不能从这些单事务 PASS 推导出任意并发工作负载的保证；后续整体装配必须专门复核这一调度范围。

生产登录/采购/订阅/续费、真实软件安装、真实工具/账号、生产迁移与清理保证均未开放。仅本机隔离 TEST 接口及 UI 替身验证；凭据只存引用，不能据此宣称真实凭据服务可用。
