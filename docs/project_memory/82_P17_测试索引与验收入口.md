报告耗时采用JSON中的runner `seconds`，包含测试发现；stderr末尾的unittest自身计时也原样保存，两者不混写。独立边界脚本耗时为外层子进程运行时间。全量中的受控失败/中断输出属于原有证据保留回归，是否通过以外层测试最终汇总为准。

Golden真实启动prepare/resume/replay三个子进程；双worker用两个同时启动的独立进程，不以同进程重建对象代替。子进程命令、stdout/stderr、退出码及耗时保存在专项stdout日志。TEST世界效果和原E5-A回执独立，最终经正常C1结果消费和Action/Evolution吸收。
