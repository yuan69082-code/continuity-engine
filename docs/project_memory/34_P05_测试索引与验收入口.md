## 5. Golden Scenario 验收点

- “我爱你”基于结构化 Perception 路由到 relationship SubjectState、相关 Memory/DerivedSummary、近期 Timeline/Event 与本地授权 Fact；
- 无关项目候选不进入 Manifest；
- secret source 被权限门拒绝，Trace 不含 secret 正文；
- fixed clock、相同输入和重建后的 Router 得到同一 RoutePlan/Manifest/Trace；
- Memory/SubjectState 仓储在路由前后 hash 不变；
- Router 结果仅为引用清单，不是 Thinking 输入或 P06 最终 Context。

## 6. 失败关闭和边界入口

- neutral/continuity purpose 只打开显式 required SubjectState，MEMORY/SUMMARY/TIMELINE/LOCAL_FACT 均 `NOT_OPENED` 且读取次数为 0；未选高 relevance 候选不能进入 Manifest；
- 两来源 total=30 时在读取前分别请求 15，requested/retrieved/evaluated/retained/rejected 可逐项复算且总读取不超过 30；
- Memory/Summary 40+40 数据量使用有界 query，公开 `list_*` 被测试替身禁止；Timeline 120 条历史仍取得近期相关窗口且 retrieve→revalidate 不自行 stale；
- 必需来源拒绝时，即使 optional source 成功，最终 REJECTED Manifest 仍为空，候选被结构化标为不可消费；
- Retrieval Budget 默认 50、配置 30—80、per-source 和 total 上限；
- unknown visibility、cross subject/environment、required source denial、optional/required source failure；
- query 与取用间 version/hash/revision 漂移；
- ARCHIVED Memory、失效/被替代 Summary、corrected/revoked Timeline target；
- Feature Gate 关闭零 source reads；
- Manifest/Trace 篡改或计数不一致失败关闭。
