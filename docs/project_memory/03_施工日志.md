**日期：** 未记录（历史阶段汇总）

**目标：** 建立可插拔记忆管理、自主唤醒基础、模型无关思考框架和只读感知层。

**完成内容：** 完成 MemoryRetriever/Recorder 端口、MemoryRetrievalResult、WakeSession/WakeContext、四类 WakeDecision、ThinkingProvider、ThinkSession、TokenBudget 接口、PerceptionContext/Result 和确定性规则。Thinking 接收 PerceptionResult，通过 ThinkSession 保存上下文摘要、预算、结果和关联信息。

**架构决策：** 固定 Wake → Perception → Thinking；Perception 成为 Thinking 唯一直接输入，且禁止修改 SubjectState。Memory 只管理检索、相关性和影响，不拥有长期存储。

**遗留问题：** 外部长期记忆库、真实 MCP、真实 ThinkingProvider、后台常驻唤醒和所有唤醒路径的统一资源入口未实现。
