## 4. 关键断言

- 三时间均为 timezone-aware UTC，且 occurredAt ≤ observedAt ≤ recordedAt；显式 recordedAt ≤ 单次读取的 appliedAt。
- `EXPLICIT/PARTIALLY_COALESCED/LEGACY_COALESCED` 不能与实际时间输入不一致。
- exact duplicate 不重复 Event/mutation/revision；重启或回退时钟下先按持久化 identity 返回原 update 与当前 state，不读取 applied clock；conflicting duplicate 优先以 identity conflict 失败关闭。
- 前向、缺失和跨 Subject 引用在持久化加载和 Timeline 重建时均失败关闭。
- FACT、OBSERVATION、INTENTION、CORRECTION、REVOCATION 无论是否迟到均不能携带 mutation；新显式 mutation 只属于 STATE_CHANGE。
- correction/revocation 只追加，原 Event 不变。
- Timeline 没有写接口，重启只从原 Event/StateUpdateRecord 历史重建。
- Golden Scenario 区分 Day 1 intention 与实际 fact，保持 Day 2 争执/和解顺序，当前关系由 SubjectState 表达为 reconciled。
- `+08:00`、`Z` 与负偏移同 instant 时查询不受本机时区影响。
- 旧 444 项基线全部继续通过；施工后实际总数不得沿用旧数字。
