## 正常入口与数据责任

`build_local_integration_app`使用可选`external_capabilities`组装原C1。第一次Thinking产生Information Need；原Action批准后，P16选择已登记且当前获准的描述，将原memory.lookup转换为内部有界QueryInput。简单查询仍为Direct，不创建Goal/Plan。复杂选择保留原Optional Planner及依赖顺序，model.generate完全保留原Thinking/ThinkSession路径。

结果核验完成后写入可重建候选缓存。下一次正常Perception经原Router/Composer获得精确候选，Thinking实际消费；不会倒写已经完成的ThinkSession或将旧输出换成新输入。原768 token预算可能明确排除外部材料；正常正向TEST显式给1024，根去重/多源对照显式给4096。Router候选数量预算与Composer输入预算分开计算。

四种本地描述统一使用内部QueryInput（kind/query/limit）和ProviderResult/ExternalCandidate结构；注册版本、capabilityRef、所需permission、credentialRef、subject/environment、到期、缓存秒数、最大候选和尝试数全部参与绑定。TEST类型为memory、knowledge、mcp查询和skill确定性处理，不代表真实MCP transport、平台SDK或产品Skill。

注册表只保存描述、禁用标记和自身revision，最多256项；缓存最多256条，容量不足明确拒绝，不偷偷驱逐未知状态。线程内全事务锁、CAS和原子替换用于本地元数据；不宣称多进程并发写或分布式一致性。缓存不保存尝试/授权执行状态，所有请求、结果和恢复记录仍为唯一E5-A。独立Fake原子回执文件属于TEST Adapter执行事实，不是第二引擎账本。

每个版本使用独立capabilityRef。新增注册不会自动安装或发现Provider；宿主必须注入匹配的Port并重建Core绑定视图，新请求才使用新版本。禁用旧版本后仍保留旧描述与Port用于原事实查询，不能重定向旧请求到新Provider。Golden明确执行了此重建过程，不宣称生产热加载或自动重连。

## 来源、权限与候选

候选包括外部source_id/source_version/content_hash、UTC观察/过期时间、confidence、external:根身份及不确定性。外部Event名称不能伪装为内部event:根。Connector完整描述hash、version、capabilityRef和permission进入精确Context材料；替换包装不能复用旧精确引用。相同根/内容/版本的包装确定性去重；不同内容仍保留共同根身份，不当成独立证据，不自动选赢家。不同真实根保留。UNVERIFIED/DISPUTED标记随原Composer进入Context；Authority始终retrieved_candidate。

缓存读取必须找到原E5-A请求，重新核实可信回执与Provider结构化结果及hash，再检查当前注册、权限、Credential引用、P15活跃状态和TTL。自洽cache hash不是执行证明；篡改cache即使重算hash也被原事实拒绝。调用后、消费前再次核验当前访问。Connector撤销/过期、凭据撤销/缺失/过期、暂停/归档/删除主体都不能继续消费或新执行。

拒绝外部查询的断言针对未授权Provider调用、候选缓存及SubjectState变化；正常C1在提出Information Need前已经合法完成的Wake/Thinking和必要审计记录不被抹除，也不笼统宣称整轮零I/O。注册冲突、受保护Fixture路径及原子写失败另有原字节不变/零写入对照。

Broker Port只接收引用和绑定，宿主保管密钥；TEST Broker把credentialRef精确绑定subject/environment/connector，版本替换保留同一连接器的合法引用。Engine没有收取API Key的字段。严格输出shape拒绝额外api_key/StateMutation字段，合成秘密与Provider异常分别检验材料拒绝和静态错误码。秘密扫描只是附加检查，不能证明任意生产输入不存在秘密。

## 恢复及失败

| 已知事实 | 处理 |
|---|---|
| 可信SUCCEEDED回执 | 原请求归账/重放，不重复执行；当前消费权限另验 |
| 明确ReceiptQuery.NOT_EXECUTED | 新执行前重新经过原Context/Action/Permission/Resource/Recoverability/Reality及P16门禁 |
| UNKNOWN、查询异常、普通NOT_EXECUTED字符串 | 保留待核实，不盲目重试，不作为未执行证明 |
| 历史回执绑定冲突/原事实不可核实 | 拒绝完成重放；账本与hash不能替代回执 |
| OFFLINE/TIMEOUT/CANCELLED/EMPTY结构化响应 | 调用完成但无可消费候选，Trace记录明确状态；不把它说成业务成功 |
| 新尝试超限 | 原E5-A已有PROPOSED次数达到描述上限，ATTEMPT_LIMIT，不再调用；仍可查询后来明确的原事实 |

显式`retry_c1_actions`复用原请求身份。P16绑定最多1—3次，本Fixture为2；同一可信Frozen Clock下计数仍从带稳定序号的原PROPOSED记录推导，未建立新计数账本。重复submit默认不自动重试。查询纯本地且成本0，原费用/结果重放的非零成本兼容由原P08/E5-A回归覆盖。不宣称任意生产Adapter exactly-once。

主体暂停发生在Adapter实际完成、结果未保存之间时，P16可恢复原E5-A SUCCEEDED事实且不消费材料。原C1完成结果另有严格revision契约：如果合法暂停已经推进SubjectState，旧完成结果明确拒绝发布过时state摘要；测试分别核对事实已恢复、拒绝原因、零重复调用和后来状态未被覆盖。此限制不通过修改冻结完成契约消除。
